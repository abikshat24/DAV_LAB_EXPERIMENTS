# Data Analytics and Visualization Laboratory

## Overview

This repository contains the laboratory experiments completed as part of the **Data Analytics and Visualization** course. The experiments demonstrate the practical application of data preprocessing, exploratory data analysis, statistical analysis, hypothesis testing, and data visualization using Python. The objective of this repository is to provide a structured collection of implementations that strengthen the understanding of fundamental data analytics concepts through hands-on experimentation.

---

## Experiments Included

### Experiment 1 – Introduction to Data Analytics

This experiment introduces the Python environment and the essential libraries used in data analytics. It focuses on implementing basic operations using NumPy and Pandas, along with creating simple visualizations using Matplotlib and Seaborn.

### Experiment 2 – Data Preprocessing

This experiment focuses on preparing datasets for analysis. It includes techniques such as handling missing values, cleaning inconsistent data, transforming variables, and performing exploratory data analysis to understand the characteristics of the dataset.

### Experiment 3 – Statistical Analysis

This experiment demonstrates the application of descriptive statistics and correlation analysis to identify relationships within the dataset. Various statistical measures and visualization techniques are used to summarize and interpret the data effectively.

### Experiment 4 – Hypothesis Testing

This experiment implements statistical hypothesis testing techniques, including Normal Distribution, Z-Test, Independent T-Test, and One-Way ANOVA. These methods are used to analyze datasets, compare groups, and draw statistically significant conclusions.

### Experiment 5 – Model Building and Validation

This experiment focuses on building and validating predictive models using diabetes datasets. It includes Linear Regression, Logistic Regression, and Time Series Analysis to evaluate model performance, analyze relationships, and identify trends and patterns in the data.

## Installation

Clone this repository using the following command:

```bash
git clone https://github.com/abikshat24/DAV_LABEXPERIMENTS.git
```

Install the required Python libraries:

```bash
pip install numpy pandas matplotlib seaborn scipy statsmodels scikit-learn
```

Open any notebook using Jupyter Notebook or JupyterLab and execute the cells sequentially to reproduce the results.
